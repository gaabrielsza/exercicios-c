# Exercícios de C

Exercícios de programação em C feitos na faculdade (Ciência da Computação, UNICAP), para praticar entrada e saída de dados, condicionais e laços de repetição.

## Exercícios

| Arquivo | Descrição |
|---|---|
| `soma_dois_numeros.c` | Lê dois inteiros e mostra a soma |
| `media_tres_notas.c` | Lê três notas e calcula a média |
| `celsius_para_fahrenheit.c` | Converte Celsius para Fahrenheit |
| `par_ou_impar.c` | Diz se um número é par ou ímpar |
| `maior_de_dois_numeros.c` | Mostra o maior entre dois valores |
| `situacao_do_aluno.c` | Classifica a média: Aprovado, Final ou Reprovado |
| `numero_no_intervalo.c` | Verifica se o número está entre 10 e 20 |
| `contagem_regressiva.c` | Conta do número digitado até 0 |
| `soma_ate_n.c` | Soma os inteiros de 1 até N |
| `conta_positivos.c` | Lê 5 números e conta os positivos |

## Como compilar e executar

Com o GCC instalado:

    gcc nome_do_arquivo.c -o programa
    ./programa

No Windows, rode `programa.exe`.

## Conceitos praticados

`scanf` e `printf` · variáveis `int` e `float` · `if / else` · operadores lógicos · `while` · `for`
